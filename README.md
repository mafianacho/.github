# mafianacho/.github

마피아나초 GitHub 조직의 공개 프로필 저장소입니다. 조직 첫 화면은 [`profile/README.md`](profile/README.md)입니다.

This is the public profile repository of the Mafianacho GitHub organization. The organization landing page is rendered from [`profile/README.md`](profile/README.md).

## 로고 · Logo assets

`profile/assets/`의 로고 파일은 마피아나초 로고 시트에서 그림 수정 없이 잘라낸 것입니다. 코드 라이선스(Apache-2.0)와 별개로, 마피아나초의 상표·브랜드 자산이며 허락 없이 다른 제품이나 서비스의 로고로 쓸 수 없습니다.

The logo files in `profile/assets/` are cut unchanged from the Mafianacho logo sheet. Independently of the Apache-2.0 code license, they are Mafianacho trademarks and brand assets and may not be used as the logo of another product or service without permission.

| 파일 · File | 용도 · Use |
|---|---|
| `logo-horizontal.png` | 가로형, 밝은 배경 · horizontal, light backgrounds |
| `logo-horizontal-dark.png` | 가로형, 어두운 카드 · horizontal, on its dark card |
| `logo-stacked-dark.png` | 세로형, 어두운 카드 · stacked, on its dark card |
| `logo-stacked-mono.png` | 세로형, 단색 · stacked, one colour |
| `logo-icon.png` | 아이콘 단독 · icon only |

`product-*.png/gif`는 각 제품 레포에 이미 있는 이미지를 같은 어두운 프레임에 자르기·확대만 해서 넣은 조직 프로필용 카드입니다.

`product-*` files are the existing screenshots of each product repository, only cropped and scaled into one identical dark frame for the organization profile.
